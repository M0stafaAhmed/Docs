# Contributing

Contributions should improve technical accuracy, readability, and safe use of the references.

## Vim reference

- Verify commands against the Vim help documentation.
- State mode requirements where relevant (Normal, Insert, Visual, Command-line).
- Distinguish Vim behavior from behavior that is specific to a distribution or plugin.
- Do not add third-party images or copied documentation without checking reuse terms.

## Sudoers reference

- Verify syntax against the sudoers manual.
- Explain the security effect of rules, tags, wildcards, run-as settings, and command specifications.
- Prefer examples that demonstrate least privilege.
- Clearly label dangerous or overly broad rules as unsafe examples.

## General

- Keep the pages dependency-light and usable offline where possible.
- Do not add analytics or remote code without documenting it.
- Do not commit personal data, credentials, tokens, or private system configuration.
