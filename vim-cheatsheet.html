🅝 Normal Mode ▼

Navigation

h Move cursor left (like left arrow).
j Move cursor down (like down arrow).
k Move cursor up (like up arrow).
l Move cursor right (like right arrow).
w Move to next word.
b Move to previous word.
0 Move to start of line.
$ Move to end of line.
gg Go to top of file.
G Go to bottom of file.
{n}G Go to line number n (e.g., 10G).
Ctrl+u Scroll up half a screen.
Ctrl+d Scroll down half a screen.
Ctrl+f Scroll forward one screen.
Ctrl+b Scroll backward one screen.

Editing

i Enter insert mode before cursor.
a Enter insert mode after cursor.
o Open new line below and enter insert mode.
O Open new line above and enter insert mode.
x Delete character under cursor.
{n}x Delete n characters (e.g., 5x).
dd Delete entire line.
{n}dd Delete n lines (e.g., 3dd).
yy Yank (copy) entire line.
p Paste after cursor.
P Paste before cursor.
u Undo last change.
Ctrl+r Redo last undone change.
r Replace single character under cursor.
s Delete character and enter insert mode.
S Delete line and enter insert mode.
dw Delete from cursor to end of word.
d$ Delete from cursor to end of line.
d0 Delete from cursor to start of line.
D Delete to end of line (alias for d$).
cw Change (delete and enter insert) to end of word.
C Change to end of line.

Clipboard

yy Yank (copy) current line.
yw Yank word under cursor.
{n}yy Yank n lines (e.g., 3yy).
p Paste after cursor or line.
P Paste before cursor or line.
"+y Yank to system clipboard (if clipboard support enabled).

Macros

qa Start recording macro into register a (q followed by a-z).
q Stop recording macro.
@a Replay macro from register a.
{n}@a Replay macro a, n times (e.g., 5@a).
@@ Replay last used macro.

Buffers

:bnext Switch to next buffer (enter in command mode).
:bprev Switch to previous buffer.
Ctrl+^ Toggle between current and alternate buffer.
:ls List all buffers.
:b {n} Switch to buffer number n.

Windows

Ctrl+w s Split window horizontally.
Ctrl+w v Split window vertically.
Ctrl+w w Cycle to next window.
Ctrl+w h/j/k/l Move cursor to window left/down/up/right.
Ctrl+w c Close current window.
Ctrl+w = Make all windows equal size.

Search & Replace

/ Search forward for pattern.
? Search backward for pattern.
n Go to next search match.
N Go to previous search match.
* Search forward for word under cursor.
# Search backward for word under cursor.

Other

:w Save (write) file.
:q Quit VIM.
:q! Quit without saving.
ZZ Save and quit (like :wq).
:help Open VIM help.

Registers

"<reg>{op} Use a register before an operator, such as "ayy to yank into register a.
"_d Black-hole delete so the registers stay untouched.
"+y Yank to the system clipboard when clipboard support is enabled.
🅘 Insert Mode ▼

Navigation & Editing

Esc Exit insert mode to normal mode.
Ctrl+[ Equivalent to Esc (exit insert mode).
Ctrl+w Delete word before cursor.
Ctrl+u Delete from cursor to start of line.
Ctrl+h Delete character before cursor (backspace).
Ctrl+l Delete character after cursor (like delete).
Ctrl+o Temporarily enter normal mode for one command, then back to insert.
Ctrl+t Increase indent (shift right).
Ctrl+d Decrease indent (shift left).

Other

Ctrl+r {register} Insert contents of register (e.g., " for unnamed register).
🅥 Visual Mode ▼

Entering Visual Mode

v Start visual character-wise selection.
V Start visual line-wise selection.
Ctrl+v Start visual block-wise selection.

Navigation in Visual Mode

h/j/k/l Extend selection left/down/up/right.
w/b Extend selection to next/previous word.
$ Extend to end of line.
0 Extend to start of line.
G Extend to end of file.
gg Extend to start of file.

Editing in Visual Mode

d Delete selected text.
x Delete selected text (alias for d).
y Yank (copy) selected text.
c Change (delete and enter insert mode) selected text.
~ Toggle case of selected text.
> Indent selected lines right.
< Indent selected lines left.

Exiting Visual Mode

Esc Exit visual mode.
Ctrl+c Exit visual mode (alternative).
: Command-line Mode ▼

File Operations

:w Write (save) the current file.
:w filename Save as a new file with the given name.
:q Quit if no changes, or if saved.
:q! Quit without saving changes.
:wq Write and quit.
:x Write if changes made, then quit (alias for :wq).

Search & Replace

:%s/old/new/g Replace all occurrences of 'old' with 'new' in the file (global).
:%s/old/new/gc Replace with confirmation for each match.
:s/old/new Replace first occurrence in current line.
:s/old/new/g Replace all in current line.

Navigation & Buffers

:n Go to next file in arguments list.
:rew Rewind to first file.
:bn Next buffer.
:bp Previous buffer.
:buffers List all buffers (alias for :ls).
{n}G Go to line n.

Other Commands

:help Open help for VIM.
:help topic Help on specific topic (e.g., :help insert).
:set number Show line numbers.
:set nonumber Hide line numbers.
:version Show VIM version info.
🅡 Replace Mode ▼

Entering & Basics

R Enter replace mode: overwrite characters as you type.
Esc Exit replace mode to normal mode.

Navigation & Editing

← → Move left/right while replacing (overwrites as you go).
Ctrl+w Delete word before cursor in replace mode.
Ctrl+h Backspace: delete previous character.
Ctrl+l Delete next character (shifts text left).

Advanced

{n}R Replace exactly n characters (e.g., 5R then type).
🅢 Select Mode ▼

Entering Select Mode

gh Start select mode character-wise (from normal mode).
gH Start select mode line-wise.
g Ctrl+h Start select mode block-wise.

Navigation in Select Mode

h/j/k/l Extend selection left/down/up/right (similar to visual mode).
w/b Extend to next/previous word.
$ Extend to end of line.
0 Extend to start of line.
G Extend to end of file.
gg Extend to start of file.

Editing in Select Mode

d Delete selected text (enters insert mode after).
c Change selected text (delete and enter insert mode).
y Yank (copy) selected text.
~ Toggle case of selected text.
> Indent selected lines right.
< Indent selected lines left.
Any printable key Start inserting/replacing at the start of selection (overwrites selection).

Exiting Select Mode

Esc Exit select mode to normal mode.
Ctrl+g Exit select mode (alternative).
🅔 Ex Mode ▼

Entering Ex Mode

Q Enter Ex mode from normal mode (full-screen ex commands).
:visual Exit Ex mode back to normal mode.

Basic Ex Commands

:print or p Print (display) current line.
{range}p Print lines in range (e.g., 1,5p).
:number or nu Print line with line number.
:list or l Print lines with unprintable characters visible.

Editing Commands

:delete or d Delete lines (e.g., 5d deletes line 5).
{range}d Delete range of lines (e.g., 1,10d).
:copy {line} or co Copy lines to after specified line (e.g., 5co10).
:move {line} or m Move lines to after specified line (e.g., 5m10).
:substitute or s Substitute in lines (e.g., s/old/new/g).

File Operations

:write or w Write (save) the file or range to file.
:quit or q Quit Ex mode or the editor.
:wq Write and quit.
:edit filename or e Edit a new file.

Other

:global /pattern/ command or g Execute command on lines matching pattern (e.g., g/foo/d).
:vglobal /pattern/ command or v Execute on lines not matching pattern.
:! Execute shell command (e.g., :!ls).
🅝 Neovim-only ▼

Built-in LSP

:LspInfo Show active LSP client and server info.
:LspStart Start the LSP client for the current buffer’s language.
:LspStop Stop the running LSP client.
:LspRestart Restart the LSP client.

Tree-sitter

:TSInstall <lang> Install Tree-sitter parser for a language.
:TSUninstall <lang> Remove Tree-sitter parser.
:TSUpdate Update all installed Tree-sitter parsers.
:TSModuleInfo Show active Tree-sitter modules for current buffer.

Terminal

:terminal Open an interactive terminal buffer inside Neovim.
Ctrl+\ Ctrl+n Exit terminal mode back to normal mode.
i Re-enter terminal insert mode.

Lua Integration

:lua print("Hello") Run inline Lua code inside Neovim.
:luafile % Source and run the current Lua file.
:help lua-guide Open Neovim’s Lua API guide.

Async Jobs

:help jobstart() Run background jobs asynchronously (non-blocking).
:help rpcstart() Start remote processes with RPC communication.

Floating Windows & UI

:help nvim_open_win() Open a floating window via API (Lua scripting).
:help nvim_buf_set_lines() Programmatically set buffer lines using Lua API.
✨ Pro Tips & Examples ▼

Useful Command Examples

:set numberShow line numbers. Use :set relativenumber for relative numbers.
:nohClear search highlighting after a search.
:%s/\s\+$//eTrim trailing whitespace from the whole file.
:%!sort -uSort the file and keep unique lines only.
:vimgrep /TODO/ **/* | copenFind TODOs across the project and open quickfix.
:g/^\s*$/dDelete blank lines using a global command.
:r !dateInsert the output of an external command at the cursor.
:vsplit +termOpen a terminal in a vertical split in Neovim.

Recommended Settings

set nocompatibleDisable vi-compat mode for modern defaults.
set mouse=aEnable mouse support when you want it.
set clipboard=unnamedplusUse the system clipboard where supported.

Operator-Pending Power Moves

ciwChange inside word.
ci"Change inside double quotes.
dapDelete around paragraph.
yipYank inner paragraph.
gg=GAuto-indent the whole file.
:%y+Copy the whole file to the system clipboard.
